* DONE Convert ShakeDraCor TEI into the Perseus corpus structure
CLOSED: [2026-08-19 Wed]
:PROPERTIES:
:CUSTOM_ID: phase1/import-shakedracor
:ASSIGNEES: Claude Code
:DEPENDS: phase0/cts-urns
:END:
=corpus-tools: import-shakedracor= (=src/shakedracor_import.py= +
=src/commands/import_shakedracor.py=) converts all 37 ShakeDraCor plays
into =data/shakespeare/{work}/shakespeare.{work}.f1.xml=, nested
per-work (matching =canonical-greekLit= and engLit's own other
textgroups, e.g. =james1/basilikon=), with a per-work =__cts__.xml=.
Reuses the existing =set-genre=/=normalize= pipeline
(=drama-act-scene-line= genre) rather than reimplementing CTS URN,
schema PI, or citeStructure logic.

Required two additions to =corpus-tools/xslt/add-citeStructure.xsl=:
- =drama-act-scene-line-cs= now also matches =div[@type='induction'
  | 'prologue' | 'epilogue' | 'chorus']= as flat (div → line) sibling
  branches alongside the nested act → scene → line structure -- these
  plays have real citable top-level divs outside the numbered acts
  (e.g. Henry V's Prologue/Chorus/Epilogue, Shrew's Induction).
- New opt-in =throughline-cs= template (=CTS-tln= refsDecl) citing
  every line by its Folger Through-Line-Number, derived from
  ShakeDraCor's own =xml:id="ftln-NNNN"=. Emitted alongside the primary
  act.scene.line refsDecl for =f1= editions specifically (not the
  Globe files, which carry no ftln ids) via a new
  =$include-tln-refsdecl= param, wired through =pipeline.py='s
  =PIPELINES["drama"]= as a pass-through override.

All 37 converted files validate against both =perseus_drama.rng= (jing)
and the corpus-tools Schematron gate. One flagged anomaly, left
untouched rather than guessed at: All's Well's =n="2.4.gap"= placeholder
(pre-existing ShakeDraCor data quirk).

The existing flat Globe files (=data/shakespeare/{work}.xml=,
=globe-eng1=... not yet renamed) are untouched -- migrating them into
the same nested layout is separate, later work, not done here.

Output informs the bibl resolver design (Phase 3).

should be flagged for manual review, not silently dropped.
